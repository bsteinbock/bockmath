# Children's Math Skills App

A React Native educational game built with **Expo**, **TypeScript**, and **Expo Router** to help children strengthen their math skills through engaging, adaptive practice.

The application focuses on:

- Addition
- Subtraction
- Multiplication
- Division
- Multiplication tables from **1×1 through 12×12**
- Adaptive practice based on individual skill mastery
- Progress tracking
- Games, challenges, rewards, and daily goals

The most important educational feature is the adaptive multiplication-fact system, which is designed to help children develop automatic recall of the 144 multiplication facts from 1×1 through 12×12.

---

## Project Status

This project is under active development.

The repository is designed to be developed incrementally, with the core math engine and multiplication mastery system serving as the foundation for the rest of the application.

See [`game_design.md`](./game_design.md) for the complete product and game-design specification.

## Product Goals

The application should feel like a **fun educational game rather than a traditional worksheet or test**.

The primary goals are to:

1. Strengthen arithmetic skills.
2. Help children develop automatic recall of multiplication facts.
3. Identify facts and skills that need additional practice.
4. Adapt future questions based on actual performance.
5. Encourage consistent practice through goals, streaks, rewards, and games.
6. Provide meaningful progress information to children.
7. Work well on both phones and tablets.

## Core Features

### Math Practice

The application supports:

- Addition
- Subtraction
- Multiplication
- Division

Questions are generated by a reusable math engine rather than being embedded in screen components.

Difficulty is configurable and designed to support additional levels in the future.

### Multiplication Tables

The application provides dedicated multiplication practice for:

- Individual tables
- Multiple selected tables
- Table ranges
- All tables from 1 through 12

For example:

- Practice the 7s
- Practice 6s and 7s
- Practice 1–5
- Practice 1–12

### Multiplication Fact Mastery

The application tracks individual multiplication facts from 1×1 through 12×12.

Each fact can maintain information such as:

- Attempts
- Correct answers
- Incorrect answers
- Accuracy
- Average response time
- Mastery score
- Last practiced time

The system should distinguish between facts that are:

- Not Started
- Learning
- Developing
- Proficient
- Strong
- Mastered

The objective is not simply to expose the child to random multiplication questions. The application should progressively identify which facts the child knows and which facts require reinforcement.

### Adaptive Practice

Question selection is adaptive.

The system considers factors such as:

- Accuracy
- Previous attempts
- Incorrect answers
- Response time
- Recent performance
- Time since last practice
- Mastery
- Selected tables
- Recently presented questions

Weak facts should receive more practice while mastered facts should continue to appear occasionally for review.

### Multiplication Fact Grid

A 1–12 multiplication grid provides a visual representation of the child's progress.

Each cell represents a multiplication fact and indicates its current mastery state.

The grid should allow the child to select an individual fact for targeted practice.

### Practice Sessions

Practice sessions can be configured by:

- Number of questions
- Operation
- Difficulty
- Selected multiplication tables
- Adaptive mode
- Optional time limit

The application provides encouraging feedback after answers.

### Games

The initial game framework includes:

- Quick Challenge
- Streak Challenge
- Multiplication Challenge
- Weak Facts Challenge

Games reuse the core math, mastery, and progress systems rather than implementing separate versions of those systems.

### Progress

The progress dashboard is intended to display:

- Overall accuracy
- Questions answered
- Current streak
- Longest streak
- Average response time
- Questions mastered
- Daily practice
- Weekly practice
- Tables mastered
- Tables in progress
- Weakest multiplication facts
- Strongest multiplication facts
- Multiplication fact grid

### Rewards

The reward system supports:

- Stars
- XP
- Levels
- Badges
- Daily streaks

Initial achievement examples include:

- First 10 Questions
- 10 Correct in a Row
- Mastered the 2s
- Mastered the 5s
- Mastered 25 Multiplication Facts
- Mastered All Multiplication Facts

### Daily Goals

Daily goals can include:

- 10 questions
- 20 questions
- 30 questions
- 10 minutes
- Custom goals

## Persistence

The application uses a persistence abstraction rather than coupling the UI directly to a storage technology.

The initial implementation may use local device storage.

The architecture should allow a future backend or cloud synchronization system to replace the local repository without requiring a rewrite of the UI or core business logic.

The data model is designed to support multiple child profiles even if the initial application uses a default profile.

## Accessibility

The application should be usable by children with different accessibility needs.

Pay particular attention to:

- Large touch targets
- Readable fonts
- Strong contrast
- Simple language
- Clear visual feedback
- Screen-reader labels
- Dynamic text sizing where practical
- Avoiding color as the sole indicator of state
- Reduced-motion preferences where practical

---

## Responsive Design

The application should work well on:

- iPhone
- Android phones
- iPad
- Android tablets

Avoid hard-coded dimensions that only work on a particular device.

Tablet layouts should take advantage of additional screen space.

The multiplication grid should become larger and easier to interact with on larger displays.

## Design Philosophy

The application should prioritize:

1. Correct mathematics
2. Effective adaptive multiplication learning
3. Reliable mastery and progress tracking
4. Child-friendly usability
5. Accessibility
6. Responsive phone/tablet behavior
7. Maintainable architecture
8. Visual polish

The application should encourage children to practice without making mistakes feel punitive.

The ultimate educational objective is to help children develop **automatic recall of multiplication facts from 1×1 through 12×12** while making the learning experience enjoyable.
